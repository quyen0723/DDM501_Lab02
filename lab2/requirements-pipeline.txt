# Slim requirements for the ml-pipeline Docker service
#
# Build prerequisites for scikit-surprise 1.1.3:
#   * scikit-surprise 1.1.3 predates Cython 3 and numpy 2 and still imports the
#     removed `pkg_resources` module. Without the pins below, a build-isolated
#     `pip install` pulls Cython 3 / numpy 2 and setuptools >= 81, which both
#     break the compile step and the runtime import.
#   * `cython<3` and `numpy==1.26.2` must be installed BEFORE surprise, and
#     surprise must be built with `--no-build-isolation` so it reuses them.
#   * `setuptools<81` is required at runtime because surprise 1.1.3 does
#     `from pkg_resources import get_distribution` at import time; setuptools
#     >= 81 removed pkg_resources.
# See Dockerfile for the exact install order.
cython<3
setuptools<81
numpy==1.26.2
pandas==2.1.3
scikit-learn==1.3.2
scikit-surprise==1.1.3
mlflow==2.9.2
matplotlib==3.8.2
seaborn==0.13.0
python-dotenv==1.0.0
